# Jiahao Keyboard 插件

eDEX-UI 风格的屏幕键盘插件，可直接向当前终端面板发送按键输入。

## 功能

- 完整 en-US 键盘布局：数字行、字母行、功能键与修饰键
- 支持 Shift、Ctrl、Alt 等修饰组合
- 物理键盘按下时同步高亮对应虚拟键
- 点击按键向当前终端发送输入
- eDEX-UI 风格的可视化按键面板

## 使用

安装后在命令面板执行 “Open Jiahao Keyboard” 打开键盘面板。聚焦终端后点击虚拟按键即可输入；连接物理键盘时，按键会在屏幕上同步显示。

## 说明

屏幕键盘本身不拦截物理键盘事件，输入仍由终端正常处理。
